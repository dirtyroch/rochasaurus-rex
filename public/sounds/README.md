# Reaction sound credits

These clips are the soundboard reactions in `public/reactions.js`. Each file is a short excerpt of a **CC0 1.0** recording (public domain): trimmed, faded, and loudness-matched so the buttons sit at a similar volume. Rex’s roar (🦖) stays synthesized in the browser.

License for every file: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). Attribution is optional. The pages below are the source recordings.

Files are mono 128 kbps CBR MP3 so Chrome, Firefox, and Safari (including mobile Safari) can decode them with the Web Audio API. Each file is under 60KB.
